2. Click **"New site from Git"**
3. Connect your Git repository
4. **Build settings:**
   - Build command: `(leave empty)`
   - Publish directory: `.` (root)
5. Click **"Deploy site"**

### **Step 2: Connect remlyx.com Domain**
1. In Netlify Dashboard → **Domain management**
2. Click **"Add custom domain"**
3. Enter: `remlyx.com`
4. **Configure DNS:**
   - Add CNAME record: `remlyx.com` → `yoursite.netlify.app`
   - Or use Netlify nameservers

### **Step 3: Wait for SSL**

- SSL verification takes 24-48 hours
- Your site will be available at `https://remlyx.com`
